## Device repair, a smoother Settings glide, the monitor's refresh rate — November 20, 2026 (unreleased)

- **Device repair (new tool, Bluetooth first).** Opening it checks Bluetooth without changing anything: whether the adapter is there and working (Windows' problem code said in plain words), its driver, whether Bluetooth is switched on, Bluetooth's services, including any Hush itself turned off earlier in Tweaks > Services, and old devices left behind. The fixes then come as guided steps, gentlest first, each asking first and checking again afterwards: quick repair (services back on, adapter restarted), reinstall driver, clean old devices you tick, and a red force clean for devices Windows refuses to remove (their pairing is backed up first). Fixes need administrator mode and are logged.
- **Software Updates** looks harder for drivers: also Windows Update directly and Microsoft Update when it is on, merged; Bluetooth drivers are recognised by their hardware too, so they land in the Bluetooth tab; a failed search shows Windows Update's own error code; when Bluetooth has a problem the card links to Device repair. Each program or driver that downloads and installs shows a bar along its row that eases toward full and completes only when the update is done.
- **Tools opens on an overview** of every tool (what each does, plus what is already known, such as "4 updates ready"); a round Back beside the title and the Tools tab return to it. It no longer opens straight into Software Updates.
- **Tweaks rows** use the Software Updates look (owner's pick A): a topic icon, the name and one line, the level as a chip, the switch at the right; a staged change gets the accent tint. Tab badges and summaries say what is active out of the total ("50/77", "50 of 77 enabled · 27 turned off by Hush · 12 running now").
- **Settings menu glide remade:** one even 350 ms slow-fast-slow glide for any distance, with the highlight moving on the same curve (no bounce) and staying on the entry you clicked.
- **Animations run at your monitor's refresh rate** (a 165 Hz screen gets 165 fps; WPF's default was 60).
- **Gauge:** the cleaning splash now starts only once the gauge shows 100 %; the "%" sign is half the size of the number.
- **Verified:** Verify.ps1 (612 PASS lines), previews looked at (Tools overview, Device repair, Tweaks Services and Privacy, Home with the small %), Perf.ps1 three times: the Settings glide budget passed all three (median 16.7–16.9 ms on the weak stand-in, which failed on some runs before); the Tweaks wheel-scroll budget passed twice (17.2, 17.3 ms) and missed once (31.6 ms) with the taller new rows; Build.ps1. **Not verified:** any real Bluetooth repair or driver search (fakes only; never run on this PC), a refresh rate above 60 Hz (this PC's monitor is 60 Hz), the glide and pulse by eye in the real window.
